# 🛍️ BaazarSetu

### AI-Powered Digital Marketplace for Artisans and Buyers

**BaazarSetu** is an AI-powered marketplace platform designed to digitally empower artisans by simplifying product creation, cataloging, pricing, translation, and market access.

The platform allows artisans to use their **phone number, voice, regional language, camera, and AI assistance** to create professional product listings and connect directly with customers and bulk buyers.

Instead of requiring artisans to manually type product details, edit photographs, translate descriptions, or determine market prices, BaazarSetu uses AI to automate these tasks.

---

## 🎯 Problem

Many traditional artisans and micro-entrepreneurs have high-quality products but face difficulties entering digital marketplaces because of:

* Limited digital literacy
* Difficulty typing product information
* Language barriers
* Lack of professional product photography
* Difficulty creating product descriptions
* Difficulty identifying product categories
* Uncertainty about appropriate pricing
* Limited access to customers outside their local market
* Limited access to B2B and bulk buyers
* Dependence on intermediaries

Existing e-commerce platforms often require sellers to understand complicated digital workflows.

**BaazarSetu simplifies the entire process using AI and voice-first interaction.**

---

# ✨ Key Features

## 1. 📱 Login Using Phone Number

BaazarSetu provides phone-number-based authentication for simple and accessible user onboarding.

### Benefits

* No complicated password management
* Easy mobile-first login
* Familiar authentication method
* Suitable for users with limited digital literacy
* Secure authenticated sessions

The authentication system is designed around the mobile experience of artisans and buyers.

---

# 2. 🗣️ Multilingual & Voice-Based Artisan Onboarding

Artisans can onboard themselves using **voice input and regional languages** rather than depending completely on typing.

The artisan can speak information such as:

```text
"My name is Ramesh.
I make handmade bamboo baskets.
I am from Chhattisgarh."
```

The system processes the voice input and converts it into structured information.

### Workflow

```text
Artisan Speaks
      ↓
Speech-to-Text
      ↓
Regional Language Processing
      ↓
Translation / Normalization
      ↓
Structured Profile Information
      ↓
Artisan Profile
```

This makes the platform more accessible to artisans who are uncomfortable with traditional text-heavy forms.

---

# 3. 📸 Camera-Based Product Upload

Artisans can use their smartphone camera to capture product photographs.

Instead of requiring professional photography equipment, the mobile application allows the artisan to:

1. Open the camera.
2. Capture the product.
3. Upload the image.
4. Let AI analyze and improve it.
5. Generate product information automatically.

### Product Upload Flow

```text
Camera
  ↓
Product Image
  ↓
Image Processing
  ↓
AI Product Recognition
  ↓
Product Information
```

# 5. ✨ AI Image Enhancement

The image-processing pipeline can include:

* Image optimization

# 🚀 Getting Started

## Prerequisites

Install:

* Git
* Node.js
* pnpm / npm
* Python 3.11+
* PostgreSQL
* Redis
* Docker *(optional)*

---

# 📥 Clone Repository

```bash
git clone https://github.com/IshanLodh0001/BaazarSetu.git

cd BaazarSetu
```

---

# ⚙️ Backend Setup

```bash
cd apps/backend
```

Create virtual environment:

### Windows

```bash
python -m venv venv
venv\Scripts\activate
```

### Linux / macOS

```bash
python3 -m venv venv
source venv/bin/activate
```

Install dependencies:

```bash
pip install -r requirements.txt
```

---

# 🔐 Environment Variables

Create a `.env` file using the provided example:

```bash
cp .env.example .env
```

Configure the required environment variables, including:

* Database connection
* Redis connection
* AI API configuration
* Authentication configuration
* Other application secrets

**Never commit API keys, passwords, JWT secrets, or other credentials to GitHub.**

---

# 🗄️ Database Migration

Run:

```bash
alembic upgrade head
```

If sample data is required:

```bash
python scripts/seed_data.py
```

---

# ▶️ Start Backend

```bash
uvicorn app.main:app --reload --host 0.0.0.0 --port 8000
```

Backend:

```text
http://localhost:8000
```

API documentation:

```text
http://localhost:8000/docs
```

---

# 📱 Mobile Setup

Move to the mobile application:

```bash
cd apps/mobile
```

Install dependencies:

```bash
npm install
```

or:

```bash
pnpm install
```

Start the application:

```bash
npm start
```

Then run it using the configured React Native development environment.

---

# 🐳 Docker

The backend includes Docker configuration.

From the backend directory:

```bash
docker-compose up -d --build
```

This can be used to start the backend services and supporting infrastructure.

---

# 🧪 Testing

Run backend tests using:

```bash
pytest tests/
```

The test suite covers backend functionality while external services can be mocked where appropriate.
